# Reverse-engineering notes — Binding of Isaac: Repentance+

## Source of truth

| Source | Location | Use |
|--------|----------|-----|
| User binary | Steam `isaac-ng.exe` (PE32 i386) | Imports, strings, signature scan |
| Import dump | `docs/pe-imports.json` | Platform call surface |
| Interesting strings | `docs/strings-interesting.txt` | Resource paths, systems |
| REPENTOGON LibZHL | `third_party/REPENTOGON/libzhl/functions/*.zhl` | Byte signatures for engine methods |
| Host scanner | `native/isaac_host.cpp` (`isaac_find_sig`, boot scan) | Runtime verification of signatures against mounted PE |

## Architecture (recovered)

```
isaac-ng.exe (C++ / Nicalis)
  ├── USER32/GDI32 — window, messages, raw input, pixel format, SwapBuffers
  ├── OPENGL32!wglGetProcAddress — all GL entry points resolved at runtime
  ├── OpenAL32 — audio
  ├── Lua5.3.3r.dll — official mod API (Afterbirth+)
  ├── steam_api.dll — Steam
  ├── EOSSDK-Win32-Shipping.dll — Repentance+ online
  ├── libcurl — HTTP
  └── CRT / KERNEL32 — threads, FS, QPC timers
```

No `SDL2.dll` import — platform abstraction is in-process Win32.

## Platform proxies (this project)

| Desktop assumption | Browser proxy |
|--------------------|---------------|
| HWND / WGL context | Emscripten canvas + WebGL2 (`isaac_init` / `isaac_set_canvas_size`) |
| OpenAL device | (host stub; OpenAL-soft emscripten still to be ported) |
| `CreateFile` / CRT `fopen` on install path | MEMFS `/isaac/...` + OPFS backing via mount UI |
| Documents saves | Virtual `/saves` (`platform/path.js` rewrite) |
| Message pump + rAF | JS `createFrameLoop` → `isaac_tick` |
| Keyboard | `platform/input.js` → `isaac_key_event` VK codes |
| Steam/EOS | Not available in browser — must soft-fail / stub for offline play |

## Threading

Binary uses threads. Host currently **single-threaded**, so this build does not require COOP/COEP; no physical Chromebook validation has been performed. `npm run serve` still accepts `COOP_COEP=1` for a future pthreads build. (The removed Path B / BoxedWine multi-threaded WASM build was the original reason that switch exists.)
